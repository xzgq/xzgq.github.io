# 1. 管理员(ecs-user/patrick)

## 1.1 初始化

### 1.1.1 设置时区

```bash
# [注意] 阿里云中默认时区可能已经是上海时区
sudo timedatectl set-timezone 'Asia/Shanghai'
```

### 1.1.2 更新apt

```bash
# [注意]
sudo apt update -y
sudo apt upgrade -qy
```

### 1.1.3 安装基础包

```bash
# [注意] 阿里云中默认安装了这些组件
sudo apt install -qy git curl wget tmux htop jq
sudo apt install -qy zsh tree git-lfs neovim dos2unix
# python3.14: pip/venv/requests
sudo apt install -qy python3-pip python3-requests
sudo apt install -qy python3-venv python3-pandas python3-psutil
```

### 1.1.4 设置防火墙，适合阿里云环境

```bash
sudo ufw allow ssh
sudo ufw allow http
sudo ufw allow 9922/tcp
sudo ufw enable
sudo systemctl restart sshd
sudo systemctl restart ufw
```

### 1.1.5 设置磁盘交换空间

```bash
SWAPFILE=/var/swapfile
sudo swapoff -a
sudo dd if=/dev/zero of=$SWAPFILE bs=1G count=6
sudo chmod 600 $SWAPFILE
sudo mkswap $SWAPFILE
sudo tee /etc/sysctl.d/99-swappiness.conf > /dev/null << EOF
vm.swappiness = 70
EOF
sudo sysctl --system
sudo tee -a /etc/fstab > /dev/null << EOF
$SWAPFILE swap swap defaults 0 0
EOF
sudo swapon -a
free -m
```
