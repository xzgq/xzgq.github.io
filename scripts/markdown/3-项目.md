# 3. 项目(xzgq)

## 3.1 初始化

```bash
PROJECT=xzgq
uv init $PROJECT

mkdir -p $PROJECT/{cpp,data,dist,docs,notebooks,scripts/{bash,python},src/$PROJECT/{cli,config,core,extract,io,load,modules/{common,eastmoney,tdx,qmt,ths},transform,utils}}

cd $PROJECT
# 参考1：https://packaging.python.org/en/latest/specifications/pyproject-toml/
# 参考2：https://docs.astral.sh/uv/concepts/configuration-files/
# 参考3: https://docs.astral.sh/uv/reference/settings/
cat >> uv.toml << EOF

[tool.uv]
package = true

[tool.uv.index]
# url = "https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple"
url = "https://mirrors.aliyun.com/pypi/simple"
default = true
EOF

uv add --dev pytest
uv add --dev ipython
uv add --dev ruff
uv add --dev requests
uv add --dev psutil
uv add --dev pandas
uv add --dev polars

```
